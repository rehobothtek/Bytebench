{% load static %} {% comment %} Shared shell for the 404 and 500 pages. 404.html and 500.html fill in the three blocks at the bottom. This deliberately does NOT extend base.html. Django renders the 500 template with no request and no context processors, so everything shop/context_processors.py provides — SITE_NAME, the cart/wishlist/compare counts, canonical_url — is simply absent there. Worse, the most common cause of a 500 is the database being unreachable, which is exactly what that context processor would then try to query, so extending base.html would turn one error into two. So this shell depends on nothing but {% static %} and {% url %}, both of which read from settings and need no request, plus a literal fallback for the site name. Tokens and the stylesheet are the site's own, so it still looks like RehoBothTek. The 404 path could have used the full base template, but the same guarantee — an error page that cannot itself fail — is worth having on both. {% endcomment %} {% block title %}Error — RehoBothTek{% endblock %} {# An error page is never a useful search result. #}
